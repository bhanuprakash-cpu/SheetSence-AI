# SheetSence-AI

SheetSence-AI is an AI-powered data analytics dashboard for non-technical users. It helps teams analyze business data with natural language instead of formulas or code.

## Problem Scope

The dashboard should support:

- Uploading **CSV** and **Excel** files
- Ingesting **Excel data links**
- Uploading **screenshots** and **images** that contain tabular or numeric data
- Asking questions in natural language to generate:
  - Charts
  - Tables
  - Summaries
  - Actionable insights

This enables faster, data-driven decisions without requiring spreadsheet expertise.

## Planned Future Enhancements

- Automated insight generation
- Advanced visualization options
- PDF report export
